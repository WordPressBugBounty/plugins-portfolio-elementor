# PowerFolio - Portfolio & Image Gallery for Elementor

## Overview

PowerFolio is a powerful WordPress plugin that allows you to create beautiful portfolios and image galleries using Elementor, Gutenberg blocks, or any page builder. The plugin comes in both free and PRO versions, with the PRO version offering advanced features.

This documentation is organized into sections for both non-technical users and developers.

## Free vs. PRO Features

### Free Version Features
- Portfolio Widget for Elementor
- Image Gallery Widget for Elementor
- Gutenberg Blocks for Portfolio and Image Gallery
- Grid and Masonry layouts
- Category filtering
- Basic hover effects
- Fully responsive design

### PRO Version Exclusive Features
- **Grid Builder** - Customize width and height of each item in galleries
- Portfolio Carousel Widget
- Post Grid Widget
- Product Grid Widget for WooCommerce
- Special and exclusive layouts
- Multiple hover effects and animations
- Advanced customization options
- Compatibility with any post type
