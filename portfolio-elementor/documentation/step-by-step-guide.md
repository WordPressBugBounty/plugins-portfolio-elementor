# Guia Passo a Passo: Criando um Portfólio Filtrável com PowerFolio

Este guia passo a passo te levará pelo processo completo de criação de um portfólio filtrável profissional usando o plugin PowerFolio e o Elementor.

## Visão Geral do Processo

O processo de criação de um portfólio filtrável pode ser dividido em 4 etapas simples:

1. **Instalação do Plugin**
2. **Adição de Itens de Portfólio**
3. **Exibição do Portfólio na Página**
4. **Configuração e Personalização**

Vamos passar por cada etapa detalhadamente.

## Etapa 1: Instalação do Plugin

1. No painel do WordPress, vá para **Plugins → Adicionar Novo**
2. Na caixa de pesquisa, digite "PowerFolio"
3. Localize o plugin "Portfolio & Image Gallery for Elementor | PowerFolio" e clique em "Instalar Agora"
4. Após a instalação, clique em "Ativar"
5. Você verá um novo menu chamado "Portfolio" no painel lateral do WordPress

## Etapa 2: Adição de Itens de Portfólio

### Criando Categorias de Portfólio

Antes de adicionar itens, é uma boa ideia criar categorias para organizá-los:

1. Vá para **Portfolio → Categorias de Portfolio**
2. Adicione novas categorias para seu portfólio (ex: Web Design, Fotografia, Gráficos, etc.)

Alternativamente, você pode criar categorias durante a adição de um item de portfólio.

### Adicionando Itens de Portfólio

1. Vá para **Portfolio → Adicionar Novo Item**
2. Adicione um título para seu projeto
3. Adicione uma descrição no editor de conteúdo
4. No painel lateral direito:
   - **Categorias de Portfolio**: Selecione uma categoria existente ou crie uma nova clicando em "Adicionar Nova Categoria"
   - **Imagem Destacada**: Clique em "Definir imagem destacada" para adicionar a imagem principal do projeto

5. Clique em "Publicar" quando terminar

6. Repita o processo para adicionar mais itens ao seu portfólio

## Etapa 3: Exibição do Portfólio na Página

1. Crie uma nova página ou edite uma existente com o Elementor
2. Clique no botão "+" para adicionar um novo widget
3. Pesquise por "portfolio" e localize o widget "PowerFolio Portfolio"
4. Arraste o widget para a seção onde deseja exibir seu portfólio
5. O portfólio será exibido automaticamente com as configurações padrão

## Etapa 4: Configuração e Personalização

Após adicionar o widget de portfólio, você pode personalizar sua aparência e comportamento:

### Configurações de Conteúdo

1. **Número de Projetos para Mostrar**: Defina quantos itens deseja exibir (padrão: 12)
2. **Mostrar Filtro de Categoria**: Escolha "Sim" para exibir filtros por categoria
3. **Texto do Botão "Todos"**: Personalize o texto do botão "Todos" (ex: "Todos os Projetos")
4. **Usar Margem de Item**: Escolha "Sim" para adicionar espaço entre os itens
5. **Estilo de Grade**: Escolha entre "Box" ou "Masonry"
6. **Número de Colunas**: Selecione quantas colunas deseja (1-4)
7. **Link Para**: Escolha para onde os itens devem linkar quando clicados:
   - **Página do Projeto**: Abre a página individual do item
   - **Lightbox**: Abre a imagem em um lightbox
   - **URL Personalizada**: Direciona para um URL específico

### Configurações de Estilo

No painel lateral, vá para a guia "Estilo" para personalizar a aparência:

1. **Estilo Geral**:
   - Cor de fundo do portfólio
   - Cor de fundo dos itens
   - Margens e preenchimentos

2. **Estilo do Filtro**:
   - Cores dos botões de filtro
   - Espaçamento entre botões
   - Tipografia dos botões

3. **Estilo dos Itens**:
   - Cor de sobreposição do item
   - Cor do título
   - Cor da categoria

### Configurações Avançadas

Na guia "Avançado", você pode configurar:

1. **Espaçamento**: Margens e preenchimentos adicionais
2. **Animações**: Efeitos de entrada para os itens
3. **Responsividade**: Comportamento em diferentes tamanhos de tela

## Visualização e Teste

Após configurar todas as opções, clique em "Atualizar" para salvar suas alterações. Em seguida:

1. Visualize sua página para ver o portfólio em ação
2. Teste os filtros de categoria para verificar se estão funcionando corretamente
3. Verifique se o lightbox está funcionando, se habilitado
4. Teste a visualização em dispositivos móveis para garantir que o design seja responsivo

## Dicas Extras

- **Para melhor desempenho**: Otimize suas imagens antes de fazer upload
- **Para portfólios grandes**: Considere habilitar a paginação
- **Para destaque visual**: Use o layout Masonry para criar uma grade mais dinâmica
- **Para mostrar detalhes**: Personalize a página individual do projeto para cada item

## Solução de Problemas

**Os filtros não estão funcionando:**
- Certifique-se de que atribuiu categorias aos seus itens de portfólio
- Verifique se a opção "Mostrar Filtro de Categoria" está definida como "Sim"

**As imagens não aparecem corretamente:**
- Verifique se você definiu imagens destacadas para cada item
- Tente regenerar miniaturas usando um plugin como "Regenerate Thumbnails"

**O layout parece quebrado:**
- Ajuste o número de colunas para corresponder à quantidade de itens
- Verifique se há conflitos com outros plugins ou com o tema
