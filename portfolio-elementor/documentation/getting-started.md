# Getting Started with PowerFolio

## Installation

1. **Upload the Plugin**:
   - Go to your WordPress admin area and navigate to "Plugins" → "Add New"
   - Click the "Upload Plugin" button at the top of the page
   - Choose the `portfolio-elementor.zip` file and click "Install Now"
   - After installation, click "Activate Plugin"

2. **Alternative Installation via FTP**:
   - Extract the `portfolio-elementor.zip` file on your computer
   - Upload the entire `portfolio-elementor` folder to your `/wp-content/plugins/` directory
   - Activate the plugin through the 'Plugins' menu in WordPress

## Initial Setup

### Portfolio Post Type

After activation, PowerFolio creates a new post type called "Portfolio" in your WordPress admin menu.

1. **Create Portfolio Items**:
   - Go to "Portfolio" → "Add New Item"
   - Add a title, description, and featured image for your portfolio item
   - Assign it to a "Portfolio Category" (this will be used for filtering)
   - Publish your portfolio item

2. **Organize with Categories**:
   - Go to "Portfolio" → "Portfolio Categories"
   - Create categories to organize your portfolio items
   - These categories will be used for filtering in your portfolio grid

### Plugin Settings

Configure the plugin settings by going to "Portfolio" → "Settings" in your WordPress admin menu.

1. **General Settings**:
   - Configure default settings for your portfolios and galleries
   - Set default lightbox options
   - Configure portfolio post type options

2. **License Activation** (PRO version only):
   - Enter your license key to enable automatic updates and premium features
   - Your license key can be found in your purchase receipt or account dashboard

3. **Enable Elementor for Portfolio Posts**:
   - Go to Elementor → Settings → Advanced
   - In the "Post Types" section, make sure "Portfolio" is enabled
   - Click "Save Changes"
   - This will allow you to edit individual portfolio items using Elementor
