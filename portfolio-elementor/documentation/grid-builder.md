# PowerFolio Grid Builder (PRO Feature)

The Grid Builder is an exclusive feature of PowerFolio PRO that allows you to customize the width and height of each item in your galleries and portfolios, creating unique and personalized layouts.

## What is the Grid Builder?

The Grid Builder allows you to create custom grid layouts, going beyond pre-defined layouts like masonry or grid. With this feature, you can:

- Define specific sizes for each item in the grid
- Create asymmetrical layouts with featured items
- Combine with Packery layout to create dynamic and exclusive grids
- Maintain filtering functionality while using custom layouts

## How to Access the Grid Builder

1. Edit a page with Elementor
2. Add the "PowerFolio Portfolio" or "PowerFolio Image Gallery" widget to your page
3. In the widget settings section, look for the "Layout" option and select "Special Grid"
4. The "Grid Builder" section will appear in the widget settings

## Using the Grid Builder

### Individual Item Configuration

For each item in your portfolio or gallery, you can define:

1. **Width** - How many "units" of width the item should occupy
   - 1 unit = default width of an item
   - 2 units = twice the default width
   - etc.

2. **Height** - How many "units" of height the item should occupy
   - 1 unit = default height of an item
   - 2 units = twice the default height
   - etc.

### Layout Examples

#### Featured Layout

A layout where the first item is larger than the others:
- Item 1: Width 2, Height 2
- Remaining items: Width 1, Height 1

#### Magazine Layout

An asymmetrical layout that resembles a magazine:
- Item 1: Width 2, Height 1
- Item 2: Width 1, Height 2
- Item 3: Width 1, Height 1
- Item 4: Width 2, Height 2
- Remaining items: Width 1, Height 1

## Combining with Filters

The Grid Builder works perfectly with the filtering functionality. When users filter by category, the layout automatically reorganizes, maintaining the proportion of items while adjusting to the new filtered set.

## Tips for Best Results

1. **Plan your layout in advance** - Consider which items should be highlighted and how the layout should flow
2. **Use images with appropriate proportions** - For items that occupy more space, use higher resolution images
3. **Test different filter configurations** - See how your layout behaves when users filter by category
4. **Combine with Packery layout** - For the best visual results, use the Grid Builder with the Packery layout option
5. **Keep responsiveness in mind** - Very complex layouts may not work well on mobile devices

## Limitations

- The Grid Builder is available only in the PRO version of PowerFolio
- The maximum number of width and height units may vary depending on your theme configuration
- For very complex layouts, consider the impact on page performance
